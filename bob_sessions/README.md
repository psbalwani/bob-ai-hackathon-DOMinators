# Bob Session Reports

This folder contains IBM Bob task session exports for the DOMinators team submission.

Each task session includes:
- A **screenshot** of the task session consumption summary (`.png`)
- An **exported task history** markdown file (`.md`)

## How these were collected

1. Opened Bob IDE → **Views and More Actions** → **History**
2. Selected each task related to this project submission
3. Clicked the task header to view the session consumption summary
4. Took a screenshot of the summary
5. Used the **Export task history** icon to download the `.md` file
6. Repeated for all relevant tasks
7. Uploaded all files into this folder

> **Security note:** All credentials and API keys have been removed from the codebase
> before exporting these session reports, per the IBM Hackathon submission guidelines.
