# Project instructions for AI agents (Claude Code, IBM Bob, or any other assistant)

## MANDATORY: CHECKLIST.md

`CHECKLIST.md` at the repo root is the master submission checklist for this hackathon project (all 4 build tracks + template/submission requirements). Deadline: 15 Sep 2026, 11:45 PM.

**Rule: any time you finish a task that corresponds to an item in `CHECKLIST.md`, you must check it off (`- [x]`) before ending your turn or reporting the task as done.**

- Only check a box when the work is actually verifiable — real code/content exists, not a stub.
- If work is partial, leave the box unchecked and add a short sub-note instead.
- If you do work not covered by an existing line, add a new checklist line rather than leaving it untracked.
- Never delete, renumber, or reword existing checklist items — only tick them or annotate.
- Read `CHECKLIST.md` at the start of a session to know what's already done before starting new work.

See `docs/03_team_division.md` for track ownership and `docs/05_api_contracts.md` / `docs/04_data_schema.md` for the frozen contracts each track must respect.
